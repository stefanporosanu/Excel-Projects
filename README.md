# 📊 Excel Data Analysis Project

> **Data Technician Bootcamp Project | Microsoft Excel | Retail & Sales Data Analysis**

## 🔎 Project Overview

This project was completed as part of a **Data Technician Bootcamp** and demonstrates practical Microsoft Excel skills used to organise, analyse and visualise **retail and sales data**.

The project involved working with customer, product, sales, commission and regional data to identify patterns, summarise performance and present findings in a clear and meaningful way.

---

## 🛠️ Skills & Techniques Used

### 🧮 Excel Formulas & Functions

A range of Excel functions were used to calculate, transform and analyse data:

| Function | Application |
|---|---|
| `SUM` | Calculated totals such as sales and commission |
| `SUMIF` | Calculated totals based on specific criteria |
| `AVERAGE` | Calculated average values |
| `AVERAGEIF` | Calculated averages based on conditions |
| `DATE` | Worked with and created date values |
| `MONTH` | Extracted month information from dates |
| `YEAR` | Extracted year information for analysis |
| `UNIQUE` | Identified distinct values within datasets |
| `VLOOKUP` | Retrieved information from related tables |
| `SWITCH` | Categorised sales performance into High, Medium and Low groups |

---

## 🔍 Data Analysis

The project involved applying several core Excel data analysis techniques:

- 🔹 Filtering datasets to focus on relevant records
- 🔹 Sorting numerical and categorical data
- 🔹 Organising and formatting structured datasets
- 🔹 Comparing sales performance across products and locations
- 🔹 Analysing customer demographics
- 🔹 Identifying trends and patterns within retail data
- 🔹 Calculating totals, averages and conditional metrics

---

## 📑 PivotTables

**PivotTables** were used to transform raw datasets into structured summaries and make comparisons easier.

Analysis included:

- 🌍 Country
- 📍 County
- 🛍️ Product
- 👥 Customer age group
- 👤 Gender
- 📈 Sales volume
- 💰 Profitability

PivotTables helped summarise larger datasets efficiently and identify differences in performance across customer and product segments.

---

## 📊 Data Visualisation

Excel charts were created to communicate findings clearly and make trends easier to interpret.

Visualisations included:

- 📈 **Revenue vs. Profit Trends**
- 🌍 **Product Revenue by Country**
- 👥 **Revenue by Customer Age Group**
- 📊 **Sales Performance Comparisons**

These visualisations helped convert spreadsheet data into clear and accessible business insights.
